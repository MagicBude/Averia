# ADR-0001：PostgreSQL 为唯一事实源

- 状态：已接受
- 日期：2026-09-21

## 决定

本机和公网统一使用 PostgreSQL。正式实体、草稿、来源观察、冲突裁决、举报和审计均写入 PostgreSQL；CSV、JSON 和 XLSX 仅作为确定性导出物。

## 原因

公开网站需要并发写入、事务、后台审核、权限、备份和托管能力。本机 SQLite、公网 PostgreSQL 会造成搜索、类型和迁移行为漂移；CSV 无法可靠承载跨表事务及发布工作流。

## 后果

本机设置比 SQLite 稍复杂，但学习和生产环境保持一致。迁移文件必须进入 Git；生产数据库不得进入 Git。
