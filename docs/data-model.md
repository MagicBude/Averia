# 数据与检索模型

## 核心实体

- `people`：人物统一档案，不以姓名作为主键。
- `person_aliases`：各语言姓名、艺名和有效时期。
- `career_events`：出道、引退、复出和休业时间线，支持日期精度。
- `organizations` / `affiliations`：事务所、厂牌、制作商和合作时期。
- `works`：内容层面的作品主记录。
- `releases`：编号、发行日期、介质、时长和发行商。
- `credits`：人物在作品中的署名和关系。
- `tags` / `work_tags`：受控词表、层级、同义及弃用关系。
- `sources` / `observations` / `resolutions`：来源声称、字段冲突和人工裁决。
- `media_assets`：图片来源、权利状态和最后验证时间。
- `reports` / `audit_log`：举报、隐藏和管理员行为。

## 未知不是空字符串

字段应区分未知、未公开、存在冲突和已确认。来源冲突时保存所有 Observation；前台只显示已确认值，或明确显示“资料存在差异”。

## 身份归一

同一自然人使用一个内部 ID，艺名为关联记录。可靠来源不足时保持分离并标记疑似关系。系统不得使用人脸识别、身体特征或模糊姓名自动合并。

## 搜索

搜索需归一化大小写、全半角、空格和作品编号连字符，并覆盖中文译名、日文原名、假名、罗马字和曾用名。模糊匹配仅影响排序；结果应说明命中了哪个别名。

默认排序为相关度与数据完整度，另提供发行日期、出道日期和名称排序。首期不构造人气榜。
