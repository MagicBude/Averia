# ADR-0004：扩展为本地媒体应用

日期：2026-09-12。状态：已接受（用户显式授权目录扫描、播放、媒体文件管理）。

Averia 长期目标增加类似媒体中心的本地文件浏览与播放体验。此前排除播放器和文件管理的产品边界由本决定更新；来源采集、稳定 ID、许可证隔离和正式数据写入规则继续适用。

媒体文件不是作品：一部作品可以关联多个文件。文件路径、大小、可用状态存于本机 `var/media/library.db`，不进入公共 CSV/JSON/XLSX。`work_id` 预留为 Averia 作品 ID；当前不从文件名猜测并自动绑定。

首个实现包含手动登记绝对目录、递归扫描、文件搜索、浏览器直接播放、HTTP 单 Range 和同目录改名。扫描忽略符号链接，只有完整扫描成功才标记消失文件为离线。改名先预览、后确认，不覆盖目标；通过排他硬链接后解除旧链接实现，所以文件系统必须支持硬链接。失败时报告错误，不静默降级为覆盖操作。

本地服务只监听 127.0.0.1，检查 Host、Origin 和每次启动生成的请求令牌。当前不支持局域网开放或多用户部署。播放兼容性取决于浏览器与视频编码，尚未引入 FFmpeg 转码。

文件系统与 SQLite 无法共享原子事务；如果改名已完成而索引写入失败，应重新扫描恢复。后续需要持久操作日志、崩溃恢复、跨目录移动和可恢复删除，完成后才能提供批量文件管理。

本轮只操作自动生成的测试文件，未扫描或修改用户真实媒体。未复制 Emby 或 JavBoss 代码及资产。
