# 产品定义

## 一句话定位

Averia 是面向全球中文用户的成人影视人物档案、作品关系和多维检索网站。

## 价值排序

1. 多条件检索与筛选
2. 人物档案
3. 作品及出演关系
4. 有品质的视觉浏览
5. 浏览器本地收藏、私有标签和备注

## 收录边界

- 职业演员与经可靠来源确认的艺名关系
- 可验证的成人正式发行作品及其发行版本
- 公开的非成人影视履历与职业社交链接
- 明确排除年龄不明、疑似未成年、偷拍、泄露、非自愿和私人信息
- 不保存住址、私人联系方式或与职业无关的真实身份信息

## MVP

- 人物和作品档案
- 人物—作品双向关联
- 跨中文、日文、假名、罗马字和别名的搜索
- 同组 OR、跨组 AND 和排除条件
- 筛选状态可复制到 URL；私人收藏状态不得出现在 URL
- 安全/完整浏览模式
- 本地收藏、标签、备注及带版本号的 JSON 导入导出
- 后台草稿、审核、发布和结构化报错
- 半自动导入候选；不允许来源直接覆盖正式数据

不属于 MVP：完整多语言界面、热度榜、个性化推荐、账号同步、公开 API、真实 Provider 和本地视频管理。

## 产品家族

- **Averia**：公共可信资料、公开网站、后台治理和未来 API。
- **Localogue**：本地文件、私人修订、播放和更完整的个人媒体库。
- `jav-idol-db`：旧项目，不再并行开发；本次决定不迁移其真实数据。
