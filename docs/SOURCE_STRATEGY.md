# Averia 数据源策略

Averia 的目标不是“找一个网站全部照抄”，而是建立**日文原始数据优先、来源可追溯、可以交叉验证**的多源元数据资料库。

## 核心原则

1. **厂商官方日文源优先**：厂商自己的作品标题、女优名、品番、发行日期、Label / Series 等字段优先采用其官方日文页面。
2. **日文原生发行平台作为广覆盖补充**：后续再接入 MGS 等日本平台，补足单一厂商官网无法覆盖的问题。
3. **来源语言不可混淆**：英文来源的翻译标题不能覆盖 `title_ja`；英文名不能覆盖 `name_ja`。
4. **官方结构化接口优先于网页抓取**：如果未来能合法获取 DMM/FANZA Web API 资格，仍优先采用官方 API，而不是 HTML。
5. **任何来源都不是绝对真理**：所有字段都应保留来源记录，冲突通过后续 Observation / Resolution 机制裁决。
6. **Provider 永远不直接写正式 CSV**：始终经过 canonical JSON → Prepare → Report → Apply。

## 当前来源层级

### A+：厂商官方日文站

V0.4 首个实现：**MOODYZ 官方站**。

适合字段：

- `title_ja`
- 主番号 / 品番
- 女优日文名
- 発売日
- レーベル
- シリーズ
- ジャンル
- 収録時間
- 厂商内部女优 ID / 作品 ID

对于该厂商自己的作品，这是当前 Averia 最高优先级之一。

后续可以逐步增加其它日本厂商官方 Provider。每个站点先独立验证页面结构，不因为“看起来相似”就直接共用 Parser。

### A：FANZA / DMM Web API（保留接口位，当前延期）

DMM/FANZA 仍然是非常有价值的广覆盖日文结构化来源，但 Web API 使用资格与 DMM Affiliate 注册绑定，而当前注册流程需要日本国内收款账户。

Averia 不使用虚假、借名或不符合规则的账户绕过注册要求，因此 V0.4 不依赖 DMM API。

未来如果合法取得 API 使用资格，可以重新启用这一来源，并通过环境变量读取凭据。

### B+：MGS 等日本正规发行 / 配信平台

定位：

- 补充厂商官网覆盖不到的作品
- 处理独占作品和不同发行体系
- 提供日文标题、女优、メーカー、シリーズ、ジャンル等交叉信息

后续在官方厂商 Provider 稳定后评估接入。

### C：英文聚合 / 二次整理来源

#### JAVDatabase

继续保留为**英文补充源 / 交叉验证源**。

适合：

- Content ID
- 英文标题
- 英文女优名 / 罗马字别名
- 演员表交叉核对
- 历史资料补缺

不再作为以下字段的日文主数据依据：

- `title_ja`
- `name_ja`
- 日文ジャンル
- 日文メーカー / シリーズ标准名

## 字段优先级

| 字段 | 首选 | 次选 | 交叉验证 |
| --- | --- | --- | --- |
| `title_ja` | 厂商官方 | 日本发行平台 | 不用英文翻译覆盖 |
| 主番号 | 厂商官方 | 日本发行平台 | JAVDatabase |
| 女优 `name_ja` | 厂商官方 / 经纪或发行官方 | 日本发行平台 | JAVDatabase JP 字段 |
| 女优 `name_en` | 明确官方罗马字 | JAVDatabase | 人工补充 |
| 発売日 | 厂商官方 | 日本发行平台 | JAVDatabase |
| 厂牌 / 系列 | 厂商官方 | 日本发行平台 | 聚合源仅校验 |
| Genre | 各来源保留原始观察值 | 映射到 Averia taxonomy | 禁止仅凭翻译自动合并 |
| Content ID | 官方发行平台 | - | JAVDatabase |
