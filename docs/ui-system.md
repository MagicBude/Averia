# UI 设计系统

## 视觉比例

- 60% 专业档案与检索
- 25% 影视卡片和海报浏览
- 15% 日系杂志式字体层级、留白与细节

避免霓虹、廉价暗黑、过量渐变和传统成人视频站风格。安全与完整模式共享信息架构；明暗主题是另一组独立设置。

## 首页

安全模式首页以全库搜索和快捷筛选为主；完整模式可增加视觉发现区。新访客默认安全模式。完整模式会话结束后恢复安全模式，未来可提供“在此设备记住”。

## 响应式策略

- 桌面：完整筛选面板、紧凑列表/卡片切换及后台。
- 手机：搜索、浏览、详情和收藏优先。
- 两端数据能力一致，不用隐藏关键功能来伪装响应式。

## 验收

主要页面依次经过线框、高保真或交互原型、桌面/手机截图、键盘与基础无障碍检查、安全模式泄露检查和真实浏览器流程。自动截图不等于用户验收。
