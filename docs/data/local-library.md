# 本地资料库格式

收藏、私有标签和备注首期只保存在浏览器本地，不进入公共数据库或分享 URL。

当前原型使用 `averia:local-library:v1` 保存人物和作品的稳定 ID、收藏、私有标签和备注，支持刷新恢复和“只看收藏”。人物与作品详情页负责编辑私有资料；独立的本地资料库页面负责汇总、导出和导入。

导出结构：

```json
{
  "format": "averia-local-library",
  "version": 1,
  "exportedAt": "2026-09-21T00:00:00.000Z",
  "items": [
    {
      "entityType": "person",
      "entityId": "稳定公开 ID",
      "favorite": true,
      "tags": ["稍后查看"],
      "note": "仅本地可见"
    }
  ]
}
```

导入会先校验格式和版本，并展示可关联与缺失实体的预览，经用户确认后才合并。同一实体的标签和备注以导入文件为准；不相关的本地条目保留。未来账号同步也不能静默上传既有本地数据。
