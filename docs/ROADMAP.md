# Averia 开发路线图

## V0.1 — 数据仓库基础

- 建立规范 CSV 数据集
- 建立稳定实体 ID
- JSON 自动导出
- 中文 XLSX 自动导出
- 数据集校验
- 来源记录 / 数据溯源基础
- 中文文档
- GitHub Actions CI

## V0.2 — 数据质量

- 重复实体检测
- 番号标准化辅助工具
- 女优别名匹配规则
- 多来源冲突报告
- 字段级 Observation
- Field Resolution 裁决记录
- 数据质量报告导出

## V0.3 — 数据导入 Pipeline

针对允许且适合程序化访问的数据来源逐步增加 Provider 适配器。

建议处理流程：

```text
获取 Fetch
   ↓
原始记录 Raw Record
   ↓
标准化 Normalize
   ↓
实体匹配 Match
   ↓
人工/规则审核 Review
   ↓
Averia 规范数据 Canonical CSV
```

禁止让未经审核的模糊身份匹配直接破坏性修改正式数据。

## V0.4 — 本地数据库

- SQLite 物化
- 姓名 / 番号搜索索引

- 保持 CSV 可重新生成数据库
- 保持数据库不是唯一数据副本
