ABOUT

Averia 是什么？

Averia 的核心不是“先做一个网站”，而是先建立一套长期可维护的数据底座。 项目当前以 CSV 作为主数据格式，并自动生成 JSON 与 XLSX；未来可在此基础上增加数据库、搜索、API 与网站界面。

项目强调稳定 ID、多来源溯源、明确的数据语言与安全导入流程，让每条数据尽可能做到“知道来自哪里、为什么采用、如何复查”。

PRINCIPLES

数据原则

JP

日文原始数据优先

作品标题、女优名称、厂商、系列与分类等语言相关字段，优先采用日本官方或日文原始来源。

SR

来源可追溯

保存来源记录与采集信息，避免无法解释某个字段最初来自哪里。

QA

先审核，再写入

外部 Provider 不直接修改正式数据；先标准化、生成报告并校验，再决定是否应用。

ID

稳定内部 ID

姓名和番号都是属性，不作为长期依赖的唯一内部主键，方便改名、别名与多番号场景。

NOTICE

项目说明

Averia 当前是开发中的元数据整理项目，不提供影片播放、下载或托管服务。

项目可能涉及成人作品的文字元数据，仅面向达到所在地法定年龄的用户。外部数据及商标归其各自权利方所有。
