# 版本路线

- **0.1**：新文档、工程骨架、PostgreSQL Schema、虚构种子、CI、设计系统和首页原型。
- **0.2**：人物、艺名、时间线、作品和发行版本的真实数据库读写与详情页。
- **0.3**：跨语言搜索、组合筛选、排除条件和 URL 状态。
- **0.4**：本地收藏、私有标签、备注和版本化导入导出。
- **0.5**：安全/完整模式、成年确认和媒体权利策略。
- **0.6**：GitHub OAuth 后台、草稿、审核、来源证据及合并拆分。
- **0.7**：半自动候选导入和结构化报错；仍不承诺真实 Provider。
- **0.8**：仅含虚构数据的公网预览。
- **1.0**：托管政策、权利流程和人工验收全部通过后，才决定是否导入首批真实资料。

每个版本都必须可运行并提供实际验收入口。自动检查通过不等于产品已经由用户接受。

## 当前可验收原型

0.1 已额外用虚构数据打通人物与作品目录的即时搜索、基础筛选、独立详情页、双向出演关系导航、基础筛选 URL 状态，以及 0.4 所规划的本地收藏、私有标签、备注和版本化 JSON 导入导出原型。页面现已通过 Repository 边界支持 `demo` 与 `postgres` 两种显式数据源，并具备幂等虚构种子；PostgreSQL 真实迁移与页面查询仍等待项目专用凭据完成运行验收，因此 0.2 尚未完成。
