# 旧版审计与重构决定

## 审计结论

旧版 Averia 是 CSV-first 元数据工具链，包含 41 位人物、45 部作品、约 1,483 行实体/关系/来源记录、派生 SQLite、多个 Provider 和二十余项测试。旧 Web 是静态表格和详情弹窗，首页突出身体字段，没有真正的安全模式、移动交互或页面信息架构。

## 最终决定

- 保留 Git 完整历史，并创建 `legacy-v0.7` 标签。
- 新主干删除全部旧文件，从零建立 Next.js + TypeScript + PostgreSQL 架构。
- PostgreSQL 成为唯一事实源；CSV、JSON、XLSX 以后只作为导出视图。
- 永久放弃旧真实数据，不执行旧数据迁移。
- 0.1 不保留、迁移或实现任何 Provider。
- 新版公开预览只含虚构数据。

## 为什么不是原地装修

旧版的数据契约、运行时数据库、静态网页和本地媒体能力长期方向互相冲突。继续叠加功能会形成 CSV/PostgreSQL 双事实源和多套产品边界。一次明确的重构比永久兼容层更容易教学、测试和维护。

## 可恢复性

旧实现仍可通过 `legacy-v0.7` 标签和提交历史查阅。未经新的来源许可审查，不得把旧数据、HTML Fixture、图片 URL 或 Provider 直接带回新主干。
