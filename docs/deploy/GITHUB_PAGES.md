# Averia GitHub Pages 发布说明

Averia 当前使用仓库 `docs/` 目录作为静态 GitHub Pages 站点源。

## 目标地址

启用后，默认地址应为：

```text
https://magicbude.github.io/Averia/
```

## GitHub 设置步骤

1. 打开 Averia GitHub 仓库。
2. 进入 **Settings**。
3. 在左侧进入 **Pages**。
4. 在 **Build and deployment** 中：
   - Source：选择 **Deploy from a branch**
   - Branch：选择 **main**
   - Folder：选择 **/docs**
5. 点击 **Save**。
6. 等待 GitHub Pages 首次部署完成。

通常稍等片刻后即可通过默认地址访问。

## 用于 DMM Affiliate 注册

页面成功公开后，可在注册页填写：

```text
附属标识：averia
网站名称：Averia
官方网站：https://magicbude.github.io/Averia/
```

最终是否通过审核由 DMM 决定；提交前建议确认站点可以在未登录 GitHub 的浏览器窗口中正常访问。

## 当前页面定位

该页面是 Averia 的公开项目主页，重点说明：

- Averia 的项目定位；
- 整理的数据范围；
- 日文原始数据优先原则；
- 数据审核与溯源原则；
- 项目开发路线；
- 不提供影片播放、下载或托管服务。

页面不依赖 JavaScript、构建工具或第三方 CDN，因此 GitHub Pages 可以直接托管。

## 后续升级

这只是早期公开主页。未来正式开发 Averia Web 后，可以将 GitHub Pages 替换为真正的 Web 应用或独立域名，而不会影响核心数据仓库。
