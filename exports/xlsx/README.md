# XLSX 导出

`averia.xlsx` 是由规范 CSV 数据自动生成的人工浏览工作簿。

V0.6 起同时提供两类 Sheet：

## 人类阅读总览

工作簿最前面固定为：

1. `女优总览`
2. `作品总览`

`女优总览` 会把女优基本资料、别名、三围和作品数聚合到一行；`作品总览` 会把女优、厂商、厂牌、系列、导演、分类等关系 ID 解引用成人类可读名称。

## 规范化数据表

之后固定按以下顺序：

1. `女优`
2. `女优别名`
3. `作品`
4. `作品番号`
5. `作品参演`
6. `作品分类`
7. `作品导演`
8. `厂商`
9. `厂牌`
10. `系列`
11. `分类`
12. `导演`
13. `数据来源`

因此 `女优` 会明确排在 `女优别名` 前面，不再受 Schema 文件名字母排序影响。

其它特点：

- 中文工作表名
- 中文表头
- 冻结首行
- 自动筛选
- 合理列宽与自动换行

XLSX 只用于浏览、筛选、检查和临时分析，不是唯一事实源。

**不要直接把 Excel 修改结果当作正式数据。**

需要更新时执行：

```bash
pnpm data:export:xlsx
```
